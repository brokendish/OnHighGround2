# Magnitude MVP 検証指示書（CODEX）
## 目的
Magnitude MVP 実装が仕様通り動作し、既存機能に影響を与えていないことを検証する。
---
# 1. Backend API 検証
## 1.1 基本レスポンス確認
```bash
curl -s "http://localhost:8080/api/earthquakes?days=1" | python3 -m json.tool

確認項目：

* HTTP 200 が返る
* items が配列
* 配列が空でもエラーにならない
* 各要素に以下が存在
    * event_id
    * occurred_at
    * epicenter_name
    * source

⸻

1.2 データ整合性

確認：

* occurred_at が ISO8601形式
* magnitude が数値または null
* lat/lng が null の場合でもAPIが正常応答
* source が “p2pquake”

⸻

1.3 件数制御

curl -s "http://localhost:8080/api/earthquakes?days=3"

確認：

* daysパラメータで件数が変わる
* 不正値でも落ちない（例: days=999）

⸻

1.4 外部API依存チェック

P2P APIは履歴APIで配列を返す仕様  ￼

確認：

* 外部APIレスポンス異常でもサーバが落ちない
* タイムアウト時に500連発にならない
* エラーメッセージが適切

⸻

2. Config 検証

curl -s "http://localhost:8080/api/admin/config" | python3 -m json.tool

確認：

* earthquake.display_days が存在
* 初期値が1
* 値変更後にAPIに反映される

⸻

3. UI 検証（最重要）

3.1 モード遷移

* 地震情報ボタンが表示される
* 押下で日本全体表示になる
* 再押下または戻る操作で通常モードへ戻れる

⸻

3.2 ピン表示

確認：

* ピンが表示される
* lat/lngありデータのみ表示される
* 重複して描画されない
* 地図移動後も残る

⸻

3.3 色分け

確認：

* 時間差で色が変わる
* 直近イベントが視覚的に目立つ

⸻

3.4 ポップアップ

確認：

* クリックで表示される
* 以下が表示される

発生時刻
震源
震度
M
深さ
津波
距離

⸻

3.5 リスト

確認：

* 新しい順
* 件数が地図と一致
* クリックで地図連動
* 選択状態が視覚的に分かる

⸻

4. 距離表示

4.1 位置情報ON

確認：

* 約xxkm が表示される
* 明らかに異常な値でない

⸻

4.2 位置情報OFF

確認：

* エラーにならない
* UI崩れない
* 距離が非表示 or 未取得表示

⸻

5. エラー耐性

5.1 外部APIダウン

確認：

* フロントにエラーメッセージ表示
* UI操作可能
* 地図は正常動作

⸻

5.2 データ0件

確認：

* 「地震情報なし」表示
* UI崩れない

⸻

6. パフォーマンス

確認：

* ピン100件程度でフリーズしない
* 初回表示が3秒以内
* 地図操作がカクつかない

⸻

7. 回帰テスト（超重要）

以下が壊れていないこと：

* ハザードレイヤー表示
* 避難所クラスタ
* 現在地表示
* ナビ機能
* サイドパネル
* 右側ボタン群

⸻

8. よくあるバグ（重点チェック）

8.1 無限再描画

* API取得ごとにピンが増殖しない

8.2 メモリリーク

* モード切替でピンが残らない

8.3 イベント重複

* clickイベントが多重登録されていない

8.4 非同期競合

* 連続クリックで壊れない

⸻

9. 合格条件

以下を満たせばOK：

* API正常
* ピン表示OK
* リストOK
* 距離表示OK
* エラー耐性OK
* 回帰問題なし

⸻

10. NG条件

以下が1つでもあれば不合格：

* 既存機能が壊れる
* UIがフリーズする
* APIが不安定
* ピン増殖バグ
