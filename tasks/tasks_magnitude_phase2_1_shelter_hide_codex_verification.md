# Magnitude Phase2-1 検証指示書（CODEX）
## Magnitudeモード中の避難所レイヤー一時非表示対応

## 目的

Magnitudeモード中に避難所レイヤーが一時非表示となり、Magnitude解除後に元の避難所表示状態へ戻ることを検証する。

また、既存の避難所表示・地震情報表示・ナビ関連機能に回帰問題がないことを確認する。

---

## 検証対象

```text
Magnitudeモード中の避難所レイヤー一時非表示
```

対象外:

```text
・新着地震の差分ハイライト
・距離順ソート
・震度フィルタ
・リアルタイム更新
```

---

# 1. 事前確認

## 1.1 サーバ起動確認

```bash
docker compose ps
```

確認:

```text
・backend が healthy
・frontend/nginx が起動
・必要なタイル/地図サービスが起動
```

---

## 1.2 Magnitude API確認

```bash
curl -s "http://localhost:8080/api/earthquakes?days=1" | python3 -m json.tool
```

確認:

```text
・HTTP 200
・items が配列
・APIが落ちていない
```

# 2. 基本動作確認

## 2.1 避難所ON状態から Magnitude ON/OFF

手順:

```text
1. 通常モードで避難所レイヤーをONにする
2. 地図上に避難所ピンまたはクラスタが表示されることを確認
3. 地震情報ボタンを押して MagnitudeモードON
4. 日本広域表示になることを確認
5. 避難所ピン/クラスタが非表示になることを確認
6. 地震ピンが表示されることを確認
7. MagnitudeモードOFF
8. 通常モードに戻る
9. 避難所ピン/クラスタが元通り表示されることを確認
```

合格条件:

```text
・Magnitude中は避難所が非表示
・Magnitude解除後に避難所表示が復元される
・地震ピン表示は維持される
```

---

## 2.2 避難所OFF状態から Magnitude ON/OFF

手順:

```text
1. 通常モードで避難所レイヤーをOFFにする
2. 地図上に避難所ピン/クラスタがないことを確認
3. 地震情報ボタンで MagnitudeモードON
4. MagnitudeモードOFF
5. 通常モードで避難所がOFFのままであることを確認
```

合格条件:

```text
・Magnitude解除後に勝手に避難所ONにならない
```

---

# 3. UI表示確認

## 3.1 一時非表示メッセージ

Magnitudeモード中に以下の趣旨の説明が表示されること。

```text
Magnitudeモード中は、地図を見やすくするため避難所レイヤーを一時非表示にしています。
```

確認:

```text
・表示位置が不自然でない
・地震リストやボタン操作を邪魔しない
・スマホ幅でも読める
```

---

# 4. 地震情報表示の回帰確認

Magnitudeモード中に以下を確認。

```text
・地震ピンが表示される
・地震リストが表示される
・リストクリックで該当ピンへ移動する
・ピンポップアップが開く
・距離表示が壊れていない
・直近地震の強調が壊れていない
```

---

# 5. 連続操作・増殖確認

## 5.1 Magnitude ON/OFF 10回連続

手順:

```text
1. 避難所ON状態にする
2. Magnitude ON/OFF を10回連続で実行
3. 最後に通常モードへ戻す
```

確認:

```text
・避難所ピン/クラスタが1系統だけ復元される
・避難所レイヤーが増殖していない
・地震ピンがOFF時に残らない
・MagnitudeパネルDOMが増殖していない
・console error がない
```

---

## 5.2 連打・非同期競合

手順:

```text
1. 地震情報ボタンを短時間に複数回クリック
2. 表示状態が破綻しないことを確認
```

確認:

```text
・地震ピンが増殖しない
・避難所表示状態が壊れない
・パネルが二重表示されない
・JSエラーが出ない
```

---

# 6. レイヤー状態確認

可能であれば Playwright またはブラウザコンソールで確認する。

確認観点:

```text
Magnitude ON:
  ・地震ピンあり
  ・避難所ピン/クラスタなし

Magnitude OFF:
  ・地震ピンなし
  ・避難所ON前提なら避難所ピン/クラスタあり
```

DOM確認例:

```text
・Magnitudeパネルは常に1つ
・地震リストDOMはON時のみ存在
・OFF時に地震リストDOMが残らない
```

---

# 7. 既存機能の回帰確認

以下を通常モードで確認する。

```text
・避難所レイヤーON/OFF
・避難所クラスタ表示
・避難所個別ピン表示
・ハザードレイヤー表示
・現在地表示
・ナビ開始
・サイドパネル開閉
・右側ボタン群
```

合格条件:

```text
・Magnitude対応前と同等に動作する
```

---

# 8. エラー確認

## 8.1 避難所レイヤー未表示時

```text
避難所が未ロード、または表示対象がない状態でも Magnitude ON/OFF が動作すること
```

## 8.2 地震API失敗時

一時的に地震APIを失敗させられる場合のみ確認。

```text
・地震情報取得失敗時も避難所表示状態が壊れない
・Magnitude OFFで通常表示に戻れる
```

---

# 9. 合格条件

以下をすべて満たすこと。

```text
・Magnitude ON時に避難所が一時非表示になる
・Magnitude OFF時に元の避難所表示状態へ戻る
・避難所OFFから入った場合はOFFのまま維持される
・地震ピン/リスト/ポップアップ/距離表示に回帰なし
・10回連続ON/OFFでDOM/レイヤー/イベントが増殖しない
・通常モードの避難所機能が壊れていない
・console error / pageerror が発生しない
```

---

# 10. NG条件

以下が1つでもあれば不合格。

```text
・Magnitude解除後に避難所表示状態が変わってしまう
・避難所レイヤーが増殖する
・地震ピンがOFF後も残る
・Magnitudeパネルが増殖する
・通常モードの避難所ON/OFFが壊れる
・JSエラーが出る
・ナビや現在地表示に影響が出る
```
