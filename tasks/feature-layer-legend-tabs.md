# タスク: レイヤー・凡例タブの統合

## 概要

左サイドパネルの「レイヤーボタン」「凡例ボタン」の**内容**を
画面下パネルのタブとして追加する。

---

## タブ構成（確定）

```
画面下パネル（変更後）
├── 操作タブ   ← 既存・変更なし
├── 情報タブ   ← 既存・変更なし
├── レイヤータブ ← 新規（左パネルのレイヤー内容を移植）
└── 凡例タブ   ← 新規（左パネルの凡例内容を移植）
```

---

## 要件

### タブの挙動
- タブ順序: 操作 / 情報 / レイヤー / 凡例
- ナビ中も全タブ使用可能（制限なし）
- デフォルト表示は操作タブのまま（変更しない）

### 左サイドパネル
- 左パネル自体は残す（廃止しない）
- レイヤー・凡例のボタン/UIは左パネルから**削除する**
- 左パネルに残すべき内容は現状のまま維持する

### コンテンツの移植方針
- レイヤー・凡例の**HTML構造とロジックをそのまま移植**する
- 動作を作り直さない・リファクタリングしない
- CSSのスコープが壊れないよう注意する

---

## 実装前のCHECKLIST

```
[ ] 1. 画面下パネルのタブHTMLがどのファイルにあるか特定した
[ ] 2. 既存タブ（操作・情報）の切り替えロジックを確認した
[ ] 3. レイヤーUIのHTML・JSがどのファイルにあるか特定した
[ ] 4. 凡例UIのHTML・JSがどのファイルにあるか特定した
[ ] 5. 左パネルで削除すべき要素（ボタン・コンテナ）を特定した
[ ] 6. レイヤー・凡例に固有のCSSクラスを確認した（スコープ確認）
[ ] 7. 修正方針を出力してから実装に入った
```

---

## 実装手順（ガイドライン）

### Step 1: タブボタンの追加

```html
<!-- 既存 -->
<button class="tab-btn" data-tab="operation">操作</button>
<button class="tab-btn" data-tab="info">情報</button>

<!-- 追加 -->
<button class="tab-btn" data-tab="layer">レイヤー</button>
<button class="tab-btn" data-tab="legend">凡例</button>
```

### Step 2: タブコンテンツの追加

```html
<!-- 既存タブコンテンツの後に追加 -->
<div id="tab-layer" class="tab-content" style="display:none;">
    <!-- 左パネルのレイヤーHTMLをそのまま移植 -->
</div>

<div id="tab-legend" class="tab-content" style="display:none;">
    <!-- 左パネルの凡例HTMLをそのまま移植 -->
</div>
```

### Step 3: タブ切り替えロジックに追加

```javascript
// 既存の切り替えロジックに 'layer' と 'legend' を追加するだけ
// 切り替えロジック自体は変更しない
```

### Step 4: 左パネルから削除

- レイヤーボタン・コンテナを左パネルから削除
- 凡例ボタン・コンテナを左パネルから削除
- 左パネルの他の要素には触らない

---

## DO NOT

- ❌ 操作タブ・情報タブの内容・ロジックを変更しない
- ❌ 左サイドパネル自体を廃止・非表示にしない
- ❌ レイヤー・凡例のロジックをリファクタリングしない
- ❌ タブ切り替えロジックを作り直さない（既存に追加するだけ）
- ❌ デフォルト表示タブを変更しない（操作タブのまま）
- ❌ ナビ中のタブ制限ロジックを追加しない（全タブ常時使用可能）

---

```
[ ] 画面下パネルに4タブ（操作/情報/レイヤー/凡例）が表示される

[ ] 凡例タブを開くと従来と同じ凡例が表示される

[ ] 左パネル自体は表示されている

```
