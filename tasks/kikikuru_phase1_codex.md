# CODEX向け検証指示書: キキクル Phase 1 表示レイヤー追加

## 目的
Claude Code が実装したキキクル Phase 1 表示レイヤー追加について、実ブラウザ・Docker環境・回帰観点で検証する。

## 検証対象
- 浸水キキクル表示レイヤー
- キキクルON/OFF UI
- 凡例
- 最終更新時刻・取得状態表示
- 取得失敗時の安全性
- 既存レイヤー・避難所・ルート表示への影響

## 重要観点
キキクルはリアルタイム危険度情報であり、固定ハザードとは意味が異なる。
以下を混同していないことを重点確認する。

- 危険度なし
- データなし
- 取得不可
- 判定不能
- 情報が古い可能性あり

`unknown` や `unavailable` を `none` として扱っていないこと。

## 検証手順
### 1. 静的チェック
以下を実行する。

- JS構文チェック
- Python構文チェック
- 追加ファイルの読み込み確認
- 未定義変数・TDZ・グローバル汚染の確認

例:
```bash
node --check frontend/js/kikikuru-layer.js
python -m compileall backend/app
```

実際のファイル名に合わせて実行する。

### 2. Docker起動確認
Docker環境を再ビルドまたは再起動し、主要サービスが起動することを確認する。

確認対象:
- frontend
- backend
- martin
- osrm-walking
- osrm-driving がある場合は osrm-driving

確認内容:
- frontend HTTP 200
- backend health HTTP 200
- ブラウザコンソールエラーなし
- 初期表示で画面が壊れない

### 3. キキクルUI確認
ブラウザで OnHighGround2 を開き、以下を確認する。

- キキクルUIが表示される
- 浸水キキクルON/OFFができる
- 洪水・土砂が未実装の場合、disabledまたは未実装表記が妥当である
- 凡例が表示される
- 最終更新時刻または取得状態が表示される
- UIがモバイル幅で崩れない
- 既存の気象カード、ハザードUI、情報タブと干渉しない

### 4. タイル表示確認
浸水キキクルをONにし、地図上にタイルまたは危険度分布が表示されることを確認する。

確認内容:
- ネットワークリクエストが成功している
- 404/403/CORSエラーが出ていない
- 対応ズームで表示される
- 非対応ズームで画面が壊れない
- 地図移動・ズーム後も表示される
- OFFにすると消える
- 再ONで再表示される

### 5. 既存表示との重なり確認
以下と同時表示して視認性を確認する。

- 避難所マーカー
- 現在地マーカー
- ルート線
- 危険区間表示
- 固定ハザードレイヤー
- 雨量レーダー

確認内容:
- キキクルが避難所やルートを完全に潰さない
- 透明度が過剰ではない
- 既存レイヤーのON/OFFが壊れない
- レイヤー順序が妥当である

### 6. 失敗系確認
可能であれば、タイルURLやバックエンドプロキシを一時的に失敗させて確認する。

確認内容:
- 取得失敗時に画面全体が落ちない
- UIに取得不可が表示される
- 古い情報を最新のように表示しない
- `none` と誤表示しない
- console error が過剰に連発しない

### 7. E2E追加
可能であれば Playwright E2E を追加する。

候補:
- `e2e/kikikuru-layer.spec.js`

テスト内容:
- キキクルUIが表示される
- 浸水キキクルをON/OFFできる
- 凡例が表示される
- 取得失敗mockでも画面が壊れない
- モバイル幅で横スクロールしない

### 8. 回帰確認
最低限、既存の代表E2Eを実行する。

候補:
- 情報タブ関連
- ハザードレイヤー関連
- 雨量レーダー関連
- 避難所マーカー関連
- ナビ表示関連

実行できないものがある場合は、理由を明記する。

## 判定基準
### PASS
- 浸水キキクルが表示できる
- ON/OFFできる
- 凡例・取得状態が表示される
- 既存主要機能に回帰がない
- 取得失敗時も画面が壊れない

### PASS with notes
- 基本機能は動くが、以下のような軽微な課題がある
  - ズーム帯の一部で表示が限定的
  - 洪水・土砂が未実装
  - 凡例・色・透明度に改善余地あり
  - stale判定が暫定

### FAIL
- 画面初期化が壊れる
- キキクルONでJSエラーにより操作不能になる
- 既存レイヤーや避難所・ルート表示が壊れる
- 取得失敗を危険度なしとして誤表示する
