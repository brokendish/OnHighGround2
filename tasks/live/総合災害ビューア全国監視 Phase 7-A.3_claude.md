# 鉄道路線オーバーレイ視認性改善

## 背景

Phase 7-A.2 で、OSM PBF から抽出した静的 GeoJSON により、鉄道路線オーバーレイ表示が実現された。

しかし現状では以下の課題がある。

* 通常路線がすべて白系で表示され、路線識別が難しい
* 鉄道に詳しくない利用者には、どの路線か判断しにくい
* ズーム時に同一路線が複数線で表示され、複雑に見える
* 障害状態を色だけで表現すると、路線識別色と衝突する可能性がある

災害時の行動判断支援では、利用者が瞬時に

* どの路線か
* どこを通っているか
* その路線が通常か、遅延か、見合わせか

を理解できる必要がある。

---

## 目的

鉄道路線オーバーレイを、より路線図に近い視認性へ改善する。

特に、路線ごとの公式カラーを使い、障害状態は線の太さ・ハロー・点線などで表現する。

---

## 基本方針

### 路線識別

鉄道会社・路線の公式カラーを優先する。

例:

```text

JR総武線各駅停車 #FFD400
JR京葉線        #E85298
JR埼京線        #00AC9A
東京メトロ銀座線 #F39700
東京メトロ丸ノ内線 #E60012
東京メトロ東西線 #00A7DB
東京メトロ千代田線 #009944
京王線          #DD0077
小田急線        #2288CC
東急東横線      #DA0442
```

厳密な色コードは、既存の公式情報・路線図・一般的に使われているラインカラーに合わせてよい。

---

## 障害状態の表現

障害状態では、路線色を変えない。

代わりに以下で表現する。

### normal

```text
路線公式カラー
細線
opacity控えめ
```

### delay

```text
路線公式カラー
通常より太線
必要に応じて黄色系ハロー
```

### partial_suspension

```text
路線公式カラー
太線
破線またはオレンジ系ハロー
```

### suspended

```text
路線公式カラー
太線
赤ハロー
必要に応じて強調縁取り
```

重要:

```text
状態色で路線色を上書きしない
```

## 推奨スタイル

### 通常路線

```text
stroke: 公式カラー
stroke-width: 1.8
stroke-opacity: 0.55
```

### 遅延

```text
stroke: 公式カラー
stroke-width: 3.5
stroke-opacity: 0.95
halo: rgba(255, 213, 79, 0.55)
halo-width: 6
```

### 一部運休

```text
stroke: 公式カラー
stroke-width: 4
stroke-opacity: 0.95
dashArray: 8 6
halo: rgba(255, 152, 0, 0.6)
halo-width: 7
```

### 運転見合わせ

```text
stroke: 公式カラー
stroke-width: 4.5
stroke-opacity: 1.0
halo: rgba(244, 67, 54, 0.75)
halo-width: 8
```

Leafletでは、必要に応じて同一GeoJSONを halo layer と main line layer の2層で描画してよい。

## 同一路線の複数線対策

ズーム時に同一路線が複数線で描画され、利用者が混乱しないようにする。

### 除外強化

GeoJSON生成または読み込み時に以下を除外する。

```text
railway=service
railway=siding
railway=yard
railway=platform
railway=station
railway=spur
service=yard
service=siding
service=spur
usage=industrial
```

### 表示対象

基本は営業路線を優先する。

```text
railway=rail
railway=subway
railway=light_rail
railway=monorail
```

ただし、駅構内線・車庫線・側線は表示しない。

---

## 代表線化

MVPでは完全なトポロジ統合までは不要。

まずは以下の簡易対応でよい。

1. name / operator / ref / line 系プロパティで路線キーを作る
2. service系線路を除外
3. 同一路線の極端な重複線は表示しない
4. zoom低〜中では主要営業線のみ表示
5. zoom高でも側線・車庫線は表示しない

## 路線カラー辞書

新規ファイル候補:

```text
frontend/js/live/live-train-line-colors.js
```

または既存 `live-train-osm-layer.js` 内に初期実装してよい。

形式例:

```javascript
const LIVE_TRAIN_LINE_COLORS = {
  "山手線": "#9ACD32",
  "中央線": "#F15A22",
  "中央線快速": "#F15A22",
  "京浜東北線": "#00A7E3",
  "総武線": "#FFD400",
  "総武線各駅停車": "#FFD400",
  "京葉線": "#E85298",
  "埼京線": "#00AC9A",
  "銀座線": "#F39700",
  "丸ノ内線": "#E60012",
  "東西線": "#00A7DB",
  "千代田線": "#009944",
  "京王線": "#DD0077",
  "小田急線": "#2288CC"
};
```

一致方法:

* 完全一致
* 部分一致
* ODPT Railway ID からの対応
* OSM name / ref / operator からの対応

色が未定義の路線は、薄グレーではなく控えめな中立色にする。

```text
fallback color: #8FA3B0
```

## 凡例

鉄道レイヤーON時に、簡易凡例を追加する。

表示内容:

```text
鉄道路線
路線色: 各路線の公式カラー
太線: 遅延
破線: 一部運休
赤ハロー: 運転見合わせ
```

既存凡例UIがある場合はそこへ統合する。

## カード連動

交通影響カードの障害路線をクリックまたはタップした場合、該当路線へフォーカスできるとよい。

MVPでは任意。

ただし、可能なら以下を実装する。

```text
カード項目クリック
↓
該当路線へfitBounds
↓
ポップアップ表示
```

---

## 完了条件

* 鉄道路線が路線ごとの公式カラーで表示される
* 障害状態でも路線色が維持される
* 遅延・一部運休・運転見合わせが線幅/点線/ハローで判別できる
* 白一色表示から脱却している
* 側線・車庫線・駅構内線が過剰に表示されない
* ズーム時に複数線が目立ちすぎない
* モバイルでも見やすい
* 災害レイヤーの視認性を壊さない
* 既存の Phase 7-A / 7-A.2 機能を壊さない
