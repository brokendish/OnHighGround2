# Phase 4-B 日月情報カード

## 目的

/live に日月情報カードを追加する。

全国監視画面において、

- 日の出
- 日の入り
- 月の出
- 月の入り
- 月齢

を表示できるようにする。

本フェーズでは監視情報としての表示のみを対象とし、
潮位・津波・高潮・危険度との連携は行わない。

---

## スコープ

実装対象:

- 日月情報カード追加
- 日の出表示
- 日の入り表示
- 月の出表示
- 月の入り表示
- 月齢表示

実装対象外:

- 危険度ランキング連携
- 潮位との相関分析
- 津波判定
- 高潮判定
- 全国地点切替
- 地図連動

---

## 基本方針

既存 OnHighGround2 で実装済みの日月計算ロジックを可能な限り再利用すること。

新規天文計算ロジックは極力実装しない。

---

## バックエンド

### API追加

```text
GET /api/live/sun-moon
```

返却例:

```json
{
  "sunrise": "04:32",
  "sunset": "18:55",
  "moonrise": "15:42",
  "moonset": "01:12",
  "moon_phase": 12.4,
  "moon_phase_name": "Waxing Gibbous"
}
```

---

### 基準地点

初期実装は固定地点でよい。

推奨:

```text
東京
```

将来的な地点切替を妨げない構造にすること。

---

### データ取得失敗時

表示:

```text
取得できません
```

とする。

危険表示へ変換しないこと。
