# 総合災害ビューア全国監視 Phase 7-A.4

# 鉄道路線名・駅名ラベル表示

## 背景

Phase 7-A.3 により、鉄道路線は公式カラーで表示されるようになり、白一色表示より大幅に見やすくなった。

一方で、現状は色付き線が表示されているだけであり、利用者が地図上で以下を即座に判断しづらい。

* どの路線か
* どの駅付近か
* 障害路線がどの地域に影響しているか
* 迂回候補になりそうな接続駅はどこか

災害時の行動判断支援として、路線名・駅名の表示を追加する。

---

## 目的

鉄道運行影響レイヤーON時に限り、ズームレベルに応じて路線名・駅名ラベルを表示する。

ただし、地図がラベルだらけにならないよう、段階表示・優先表示・表示数制御を行う。

---

## 基本方針

### 表示条件

路線名・駅名は、鉄道運行影響レイヤーON時のみ表示する。

鉄道レイヤーOFF時は、路線名・駅名ラベルも消す。

---

## 表示レベル

### zoom 8〜10

表示:

```text
主要路線名のみ
```

駅名は表示しない。

### zoom 11〜12

表示:

```text
路線名を増やす
障害路線の路線名を優先表示
```

駅名は原則表示しない。
ただし障害路線に関連する主要駅は表示してもよい。

### zoom 13〜14

表示:

```text
路線名
主要駅名
障害路線周辺駅
```

### zoom 15以上

表示:

```text
路線名
駅名
障害路線周辺駅を優先
```

ただし全駅名を無制限に表示しない。

---

## 優先順位

ラベル表示優先度は以下。

```text
1. 障害路線名
2. 障害路線上または周辺の駅
3. 主要路線名
4. 主要駅
5. 通常路線名
6. 通常駅
```

---

## 路線名ラベル

Phase 7-A.3 で集約した路線単位の feature を利用する。

表示名候補:

```text
_live_route_name
name_ja
name
name_en
ref
line
route_name
```

優先順:

```text
_live_route_name
name_ja
name
route_name
line
ref
```

### 表示位置

MVPでは線に沿ったテキストでなくてよい。

まずは以下でよい。

```text
路線 feature の bounds center
または
表示範囲内 geometry の代表点
```

重要:

* 画面外の路線ラベルを出さない
* 同一路線ラベルを大量に重複表示しない
* 1路線につき表示範囲内で1〜2個程度に抑える

---

## 路線ラベル見た目

黒背景地図で読みやすくする。

推奨:

```text
文字色: #ffffff
背景: rgba(0,0,0,0.55)
枠線: 路線公式カラー
角丸
小さめ
```

障害路線:

```text
通常より太い枠
状態ラベル付与
例: 中央線快速 遅延
例: 京王線 見合わせ
```

---

## 駅名データ

OSM PBF から駅ポイントを抽出し、静的GeoJSONとして配信する。

追加候補:

```text
frontend/layers/railways/kanto_stations.geojson
```

または既存のデータ生成スクリプトに追加する。

抽出対象候補:

```text
railway=station
railway=halt
station=subway
station=light_rail
public_transport=station
```

除外候補:

```text
railway=platform
public_transport=platform
```

プロパティ例:

```json
{
  "name": "新宿",
  "name_ja": "新宿",
  "operator": "JR東日本",
  "railway": "station",
  "station": "train",
  "network": "JR東日本"
}
```

---

## 駅名表示

### zoom 13〜14

主要駅のみ表示。

主要駅判定はMVPでは簡易でよい。

候補:

* `station=train`
* `station=subway`
* `network` が複数ある
* name が主要駅辞書に含まれる

主要駅辞書例:

```text
東京
新宿
渋谷
池袋
品川
上野
秋葉原
横浜
川崎
大宮
千葉
立川
八王子
町田
調布
北千住
押上
中野
吉祥寺
船橋
柏
```

### zoom 15以上

表示範囲内の駅名を表示。

ただし表示数上限を設ける。

例:

```text
最大 80 件
```

---

## 障害路線周辺駅の優先表示

ODPT障害路線が存在する場合、該当路線ラベルと周辺駅ラベルを優先表示する。

実装方法はMVPでは簡易でよい。

候補:

1. OSM路線featureと駅の距離が近い
2. 路線名・operator・network が近い
3. 表示範囲内の障害路線近傍駅を優先

厳密な駅・路線トポロジ判定は不要。

---

## 表示数制御

ラベル過多を防ぐ。

推奨上限:

```text
zoom 8〜10:
  route labels max 20
  station labels 0

zoom 11〜12:
  route labels max 40
  station labels max 10

zoom 13〜14:
  route labels max 60
  station labels max 40

zoom 15以上:
  route labels max 80
  station labels max 80
```

---

## パフォーマンス

以下を必須とする。

* 鉄道レイヤーOFF時は駅GeoJSONを読み込まない
* 鉄道レイヤーON後、必要になった時点で初回fetch
* 取得後はメモリキャッシュ
* pan/zoom時は debounce
* 表示範囲内のみラベル生成
* DOM要素を増やしすぎない

---

## UI/UX注意

ラベルは災害レイヤーを邪魔しないこと。

特に以下と競合しないこと。

* 雨雲
* キキクル
* 津波警報
* 地震マーカー
* 危険地域ランキング
* 潮位観測点

---

## レイヤー構成

推奨順:

```text
鉄道路線本体
障害路線ハロー
障害路線本体
駅点
路線名ラベル
駅名ラベル
ポップアップ
```

ただし、既存Leaflet pane構成に合わせること。

---

## 完了条件

* 鉄道運行影響レイヤーON時のみ路線名が表示される
* 鉄道運行影響レイヤーOFF時は路線名・駅名が消える
* zoom 8〜10 では主要路線名のみ表示される
* zoom 13以上で駅名が表示される
* zoom 15以上で駅名が増える
* 障害路線ラベルが優先表示される
* 障害路線周辺駅が優先表示される
* ラベルが多すぎて地図を潰さない
* モバイルで操作不能にならない
* 既存 Phase 7-A.3 の路線色・障害表現を壊さない
