# Claude用実装指示書

## Phase 8-B 雨雲レイヤー視認性改善：強雨優先・弱雨抑制

## 目的

全国災害ビューア LIVE の雨雲レイヤーについて、全体的に濃く表示されすぎて他レイヤーの視認性を妨げている問題を改善する。

LIVE は雨雲専用ビューアではなく、地震・津波・高潮・キキクル・鉄道・道路などを同時監視する総合災害ビューアである。
そのため、雨雲は常に主役として強く表示するのではなく、弱雨・通常雨は背景情報として薄くし、強雨・危険な雨域だけを視認できるようにする。

## 背景

現在の LIVE では雨雲タイルが全体的に濃く、以下の問題がある。

* 地震マーカーが見づらい
* 重要地震マーカーが雨雲に埋もれる
* キキクルや津波・高潮など他の警戒情報と競合する
* 鉄道・道路交通影響レイヤーの視認性が落ちる
* モバイルではボトムシート越しに雨雲が強く見え、情報密度が過剰になる

特に大地震発生時の確認で、雨雲が地震マーカーより強く見えてしまう場面があった。

## 対応方針

雨雲レイヤーを一律に薄くするのではなく、雨の強さに応じて透明度・表示強度を変える。

基本方針:

```text
弱雨・通常雨  → かなり薄く
中程度の雨    → 薄く
強雨          → 現状に近い視認性
非常に強い雨  → 強調
猛烈な雨      → 強調
```

つまり、青系の弱い雨は背景化し、黄色・赤・紫系の危険雨域だけを残す。

## 実装対象

LIVE 境界内のみ変更すること。

対象候補:

* `frontend/js/live/live-layers.js`
* 雨雲タイルレイヤー生成箇所
* 雨雲 canvas / tile 加工処理がある場合はその処理
* 必要に応じて `frontend/css/live/live.css`
* E2E追加が必要な場合は `e2e/live-rain-visibility.spec.js`

ナビ本体 `/` には影響させないこと。

## 実装案

### 案A: Canvas ピクセル加工が可能な場合

雨雲タイル画像を canvas で加工できる場合は、ピクセルごとに alpha を調整する。

概念例:

```js
function adjustRainPixelAlpha(r, g, b, a) {
  const level = classifyRainPixel(r, g, b, a);

  switch (level) {
    case 'weak':
      return Math.round(a * 0.25);
    case 'moderate':
      return Math.round(a * 0.40);
    case 'strong':
      return Math.round(a * 0.65);
    case 'veryStrong':
      return Math.round(a * 0.80);
    case 'extreme':
      return Math.round(a * 0.90);
    default:
      return Math.round(a * 0.20);
  }
}
```

分類イメージ:

```text
青・水色系       weak
緑系             moderate
黄・橙系         strong
赤系             veryStrong
紫・濃赤系       extreme
```

既存の雨雲ランキングや強雨判定で使用している色分類ロジックがある場合は、それを優先して再利用すること。

### 案B: タイル全体 opacity しか制御できない場合

もしピクセル単位の加工が困難な場合は、暫定対応としてタイル全体の opacity を下げる。

ただし本フェーズの狙いは案3であり、最終的には危険雨域だけを強く残すこと。

暫定値:

```js
opacity: 0.35
```

ただし、案Bのみで完了扱いにはしない。
案Bは fallback として扱う。

## 推奨 alpha 目安

初期値は以下を目安にする。

```text
弱雨・青系        alpha 20〜30%
中雨・緑系        alpha 35〜45%
強雨・黄/橙系     alpha 60〜70%
非常に強い雨・赤  alpha 75〜85%
猛烈な雨・紫系    alpha 85〜95%
```

実画面で濃すぎる場合は全体的に少し下げる。

## UI上の考え方

雨雲は地図背景の一部として扱う。
ただし、強雨域は災害警戒情報として視認できる必要がある。

優先順位は以下。

```text
最優先:
  津波警報
  重要地震
  キキクル危険域
  高潮警報
  鉄道・道路交通影響

背景:
  弱雨・通常雨

警戒:
  強雨・非常に強い雨・猛烈な雨
```

## レイヤー重なり確認

以下のレイヤーと同時表示したときに、雨雲が邪魔にならないこと。

* 地震マーカー
* 重要地震マーカー
* 津波警報
* 高潮警報
* キキクル
* 鉄道運行影響
* 道路交通影響
* 現在地マーカー

## モバイル確認

モバイルでは雨雲がより強く見えやすいため、必ず確認する。

確認ポイント:

* ボトムシート越しに雨雲が主張しすぎない
* 重要地震セクションが読みやすい
* 地図上の重要地震マーカーが埋もれない
* レイヤーFABやポップアップが見やすい
* 横スクロールや表示崩れがない

## 凡例

既存の凡例が雨雲強度を表示している場合、凡例自体の文言変更は不要。
ただし、必要であれば以下のような補足を小さく追加してもよい。

```text
弱雨は薄く表示
```

ただし、画面がうるさくなる場合は追加しなくてよい。

## 注意点

* 強雨域まで薄くしすぎないこと
* 赤・紫系の危険雨域は警戒情報として残すこと
* 弱雨を完全に消さないこと
* 地震・津波・高潮・キキクルの視認性を優先すること
* `/live` 以外に影響させないこと
* 既存の雨雲ランキングや強雨域判定を壊さないこと
* 既存E2Eの期待表示を壊さないこと

## 完了条件

* 弱雨・通常雨が以前より薄く表示される
* 強雨・危険雨域は十分に視認できる
* 地震マーカー、重要地震マーカーが雨雲に埋もれない
* モバイルで雨雲がボトムシート内情報の邪魔をしない
* 既存の雨雲表示、時刻スライダー、再生ボタンが壊れていない
* `/live` のみ変更されている
