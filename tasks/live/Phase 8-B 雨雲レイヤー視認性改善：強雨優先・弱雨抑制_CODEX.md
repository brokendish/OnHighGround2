# CODEX用検証指示書

## Phase 8-B 雨雲レイヤー視認性改善：強雨優先・弱雨抑制 検証

## 検証目的

全国災害ビューア LIVE において、雨雲レイヤーの表示が他の災害情報を妨げないよう改善されていることを確認する。

特に、弱雨・通常雨が背景情報として薄く表示され、強雨・危険雨域は必要な視認性を保っていることを検証する。

## 検証対象

* `/live`
* 雨雲レイヤー
* 雨雲時刻スライダー
* 雨雲再生ボタン
* 地震マーカー
* 重要地震マーカー
* キキクル・津波・高潮との重なり
* モバイルボトムシート

## 必須確認項目

### 1. 構文・起動確認

以下を確認する。

* frontend JS構文チェック PASS
* backendに変更がある場合は compile PASS
* Docker環境起動
* `/live` で console error / page error がない

### 2. LIVE境界確認

変更が `/live` 境界内に収まっていることを確認する。

確認内容:

* ナビ本体 `/` の雨雲表示に影響していない
* `/live` 専用JS/CSS中心の変更である
* 共通処理を変更した場合は影響範囲が明記されている

### 3. 弱雨・通常雨の抑制確認

弱雨・通常雨が以前より薄く表示されていること。

確認内容:

* 青・水色系の雨雲が背景化されている
* 地図ラベルや海岸線が見えやすい
* 地震マーカーが弱雨に埋もれない
* モバイルでも画面全体が雨雲色に覆われすぎない

期待:

```text
弱雨は見えるが、主役になっていない
```

### 4. 強雨・危険雨域の視認性確認

強雨域は薄くなりすぎていないこと。

確認内容:

* 黄色・橙・赤・紫系の雨域が十分に見える
* 強雨域ありバッジや危険地域表示と矛盾しない
* 強雨ランキングや危険地域表示が壊れていない
* 強雨域が災害警戒情報として認識できる

期待:

```text
弱雨は薄く、強雨は残る
```

### 5. 他レイヤーとの重なり確認

以下を同時表示して、雨雲が邪魔にならないこと。

* 地震マーカー
* 重要地震マーカー
* 津波警報
* 高潮警報
* キキクル
* 鉄道運行影響
* 道路交通影響
* 現在地マーカー

特に Phase 8-A.1 の重要地震マーカーが雨雲に埋もれないことを確認する。

### 6. 雨雲操作の回帰確認

以下が壊れていないこと。

* 雨雲レイヤーON/OFF
* 時刻スライダー
* 現在時刻表示
* 再生ボタン
* 雨雲タイル読み込み
* 強雨域あり/なし表示

### 7. モバイル確認

モバイル幅で確認する。

確認内容:

* ボトムシート越しに雨雲が濃すぎない
* 重要地震表示が読みやすい
* 地震マーカーが見やすい
* レイヤーFABが見やすい
* 横スクロールがない
* 操作不能状態がない

## E2E追加候補

可能であれば以下を追加する。

### ケース1: 雨雲レイヤー表示時に地震マーカーが見える

条件:

* 雨雲ON
* 地震ON
* 重要地震あり

期待:

* 重要地震マーカーが表示される
* マーカークリックでポップアップが表示される
* 雨雲ONでも地震ポップアップが操作できる

### ケース2: 雨雲レイヤーON/OFF回帰

期待:

* 雨雲ONでタイルが表示される
* 雨雲OFFでタイルが非表示になる
* 再ONで表示が復帰する

### ケース3: モバイルボトムシート視認性

期待:

* ボトムシート内テキストが読める
* 雨雲が背景として邪魔にならない
* 横スクロールが発生しない

* 強雨域あり

* モバイル幅
* ボトムシート表示
* 雨雲ON

## 回帰確認

以下が壊れていないこと。

* Phase 8-A.1 地震履歴・重要地震固定表示
* JMA fallback / 市区町村震度なし表示
* 津波警報カード
* 高潮警報カード
* 強雨域あり表示
* キキクル表示
* レイヤーFAB
* 交通影響カード
* 現在地ボタン
* 月日情報
* 国土交通省 河川情報リンク

## 判定基準

### PASS

以下をすべて満たす。

* 弱雨・通常雨が以前より薄い
* 強雨・危険雨域は十分に見える
* 地震マーカー、重要地震マーカーが雨雲に埋もれない
* 雨雲ON/OFF、時刻スライダー、再生ボタンが正常
* PC/モバイルで表示崩れがない
* `/live` 外へ影響していない

### PASS with notes

軽微な濃度調整余地はあるが、弱雨抑制・強雨維持・他レイヤー視認性改善が確認できる場合。

### FAIL

以下のいずれかに該当する場合。

* 弱雨がまだ強すぎる
* 強雨まで薄くなりすぎている
* 地震マーカーが雨雲に埋もれる
* 雨雲操作が壊れている
* モバイルで視認性が悪化している
* `/live` 以外に意図しない影響がある
