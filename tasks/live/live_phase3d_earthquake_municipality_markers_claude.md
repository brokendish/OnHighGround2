# Phase 3-D 地震 市区町村震度マーカー表示

## 目的

/live の地震情報表示を、代表地点1マーカー方式から、市区町村単位の震度数字マーカー表示へ改善する。

OnHighGround2 本体と同じ震度数字マーカーデザインを流用し、地震発生時にどの市区町村でどの震度が観測されたかを地図上で確認できるようにする。

---

## スコープ

実装対象:

- 市区町村単位の震度マーカー表示
- 震度数字マーカーの表示
- OnHighGround2 本体の既存震度マーカーデザイン流用
- /live 地震レイヤーへの統合
- 代表地点1マーカー方式はフォールバックとして維持

実装対象外:

- 危険地域ランキング統合
- 津波判定
- 高潮判定
- 通知機能
- 地震履歴一覧の大幅改修
- ナビ本体UI変更

---

## 基本方針

既存 OnHighGround2 本体で実装済みの市区町村震度表示・震度数字マーカーの仕組みを可能な限り再利用する。

ただし /live 専用実装として分離し、ナビ本体へ影響を与えないこと。

---

## バックエンド

既存の地震APIに市区町村別震度データが含まれている場合は、それを利用する。

不足している場合は、/live 用のレスポンスに以下のような municipal intensity 情報を追加する。

```json
{
  "municipality_intensities": [
    {
      "prefecture": "千葉県",
      "municipality": "木更津市",
      "intensity": "4",
      "lat": 35.376,
      "lng": 139.916
    }
  ]
}
```

---

## フロントエンド

### 新規または拡張対象

候補:

```text
frontend/js/live/live-earthquake-layer.js
```

既存ファイルがある場合はそれを拡張する。

---

## 表示仕様

### マーカー

市区町村ごとに震度数字マーカーを表示する。

例:

```text
5弱
4
3
2
1
```

OnHighGround2 本体の既存デザインを流用すること。

---

### ポップアップ

クリック時に以下を表示する。

```text
市区町村名
都道府県
震度
地震発生時刻
震源名
マグニチュード
```

---

## フォールバック

市区町村別震度データが取得できない場合は、既存の代表地点1マーカー表示を維持する。

市区町村別データがある場合は、市区町村マーカーを優先する。

---

## レイヤー制御

既存の地震情報レイヤーON/OFFに連動すること。

地震レイヤーOFF時:

- 代表地点マーカー非表示
- 市区町村震度マーカー非表示

地震レイヤーON時:

- 市区町村震度データがあれば震度数字マーカー表示
- なければ代表地点マーカー表示

---

## ログ

市区町村震度表示時:

```text
live earthquake municipality markers:
event_id=XXXX
count=XX
```

フォールバック時:

```text
live earthquake municipality markers unavailable, fallback to representative marker:
event_id=XXXX
```
