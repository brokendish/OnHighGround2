# CODEX 検証指示書

## 総合災害ビューア LIVE Phase 7-A.5 全国鉄道路線 PMTiles 化

## 検証目的

`/live` の鉄道路線表示が関東限定から全国対応へ拡張され、PMTilesにより表示範囲分だけ軽量に描画されていることを確認する。

また、既存の地震・雨雲・キキクル・津波・鉄道運行情報を壊していないことを確認する。

---

# Phase 7-A.5-A 検証

## 全国鉄道路線 PMTiles ベース表示

## 確認観点

### 1. PMTiles生成物

以下を確認する。

```text
railways_japan.pmtiles が存在すること
ファイルサイズが極端に異常でないこと
全国鉄道路線が含まれていること
```

可能であれば PMTiles のメタデータを確認する。

```text
bounds
minzoom
maxzoom
layers
feature count
```

### 2. `/live` 表示確認

Docker環境を起動し、`/live` を確認する。

```text
docker compose ps
backend health
frontend health
martin health 既存利用があれば
```

ブラウザで `/live` を開き、鉄道レイヤーをONにする。

確認地点例:

```text
東京周辺
大阪周辺
名古屋周辺
仙台周辺
札幌周辺
福岡周辺
```

上記の複数地域で鉄道路線が表示されること。

### 3. 関東限定でないこと

東京以外、少なくとも大阪・福岡・札幌などで鉄道路線が表示されること。

関東だけしか表示されない場合は FAIL。

### 4. OFF制御

鉄道レイヤーOFF時に、全国鉄道路線が消えること。

### 5. 低ズーム負荷

日本全体表示付近で、鉄道路線が過剰に表示されて操作不能にならないこと。

```text
console errorなし
page errorなし
極端なフリーズなし
```

# Phase 7-A.5-B 検証

## 駅・駅名表示

## 確認観点

### 1. 駅表示

鉄道レイヤーON時、一定ズーム以上で駅が表示されること。

確認地点例:

```text
新宿
大阪
名古屋
博多
札幌
仙台
```

### 2. ズーム制御

以下を確認する。

```text
低ズームでは駅名が出すぎない
中ズームで主要駅または駅アイコンが出る
高ズームで駅名が出る
```

### 3. ラベル衝突

駅名が画面を埋め尽くさないこと。
スマホ幅でも横スクロール・操作不能・大量重なりがないこと。

### 4. OFF制御

鉄道レイヤーOFF時に駅アイコン・駅名も消えること。

# Phase 7-A.5-C 検証

## 運行情報・障害情報連携

## 確認観点

### 1. 既存ODPT API

既存の鉄道運行情報APIが壊れていないこと。

```text
/api/live/railways/status
```

または既存エンドポイントを確認する。

ODPTキー未設定時は既存どおり unavailable / fallback 表示になること。

### 2. 障害カード

鉄道運行障害カードが従来どおり表示されること。

平常路線が大量にカード表示されないこと。

### 3. 障害路線強調

障害路線がある場合、PMTilesの路線ベース上で該当路線が強調されること。

マッチング失敗時でも、代表座標マーカー・カード・ポップアップが残ること。

### 4. 既存ポップアップ

ポップアップに以下が表示されること。

```text
路線名
事業者
状態
説明
更新時刻
出典
```

# 回帰検証

以下を確認する。

## 1. JavaScript構文

関連JSに構文エラーがないこと。

## 2. `/live` 基本表示

```text
page errorなし
console errorなし
初期表示成功
```

## 3. 災害レイヤー回帰

最低限以下を確認する。

```text
地震履歴が表示される
市区町村震度マーカーが履歴選択で切り替わる
雨雲レイヤーが表示される
キキクルが表示される
津波UIが壊れていない
```

## 4. モバイル確認

スマホviewportで以下を確認する。

```text
鉄道ON/OFF可能
駅名が出すぎない
地図操作不能にならない
レイヤーFABや警戒パネルを塞がない
```

# 判定基準

## PASS

```text
全国主要都市で鉄道路線が表示される
鉄道OFFで消える
低ズーム・スマホで重くなりすぎない
駅名表示がズーム制御される
既存運行情報UIが壊れていない
地震・雨雲・キキクル・津波に回帰なし
```

## PASS with notes

以下の場合。

```text
全国表示はできるが一部地域でOSMデータ品質に差がある
駅の主要/非主要判定が暫定
運行情報との路線形状マッチングが一部未対応
```

## FAIL

以下の場合。

```text
関東以外で鉄道路線が表示されない
全国GeoJSON一括ロードになっている
スマホで操作不能になる
鉄道OFFでも路線・駅が残る
既存地震・雨雲・キキクル・津波UIを壊している
```
