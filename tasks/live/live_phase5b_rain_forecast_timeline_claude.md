# Phase 5-B 雨雲予測タイムライン MVP

## 目的

/live に雨雲予測タイムライン機能を追加する。

現在の雨雲監視は「現在時刻のみ」である。

本フェーズでは JMA 高解像度降水ナウキャストを利用し、

* 現在
* +5分
* +10分
* ...
* +60分

までの雨雲予測を表示できるようにする。

---

## スコープ

実装対象:

* 雨雲予測タイムライン
* 現在〜60分先
* 5分刻み
* スライダー操作
* 再生ボタン
* 一時停止ボタン
* 現在時刻表示
* 予測時刻表示

実装対象外:

* 15時間予報
* 危険度ランキング連携
* 雨雲危険地域集計変更
* キキクル連動
* AI予測
* 雨量推定変更

---

## 基本方針

既存の雨雲レイヤー構造を活用する。

新規の気象解析ロジックは実装しない。

JMAナウキャスト予測タイルを表示する。

## API

既存 rain tile API を利用可能であれば利用する。

必要な場合のみ追加する。

推奨:

```text
/api/live/rain/timeline
```

返却:

```json
{
  "times": [
    "2026-06-03T12:00:00Z"
  ]
}
```
