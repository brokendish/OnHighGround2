# Phase 5-D 危険地域フォーカス機能

## 目的

危険地域統合ランキングから対象地域へ素早く移動できるようにする。

現在:

```text
危険地域統合ランキング
↓
地域名表示のみ
```

利用者は地図上の場所を探す必要がある。

本フェーズでは、

```text
危険地域統合ランキング
↓
地域クリック
↓
地図フォーカス
↓
対象地域強調表示
```

を実現する。

---

## スコープ

実装対象:

* 危険地域カードクリック
* 地図フォーカス
* ズーム移動
* 対象地域強調表示
* 対象イベント表示

実装対象外:

* 危険度スコア変更
* 危険地域統合ロジック変更
* AI判定
* 避難判定
* ルート提案

---

## 基本方針

Phase 5-A の

```json
{
  "integrated_dangerous_regions": []
}
```

を利用する。

新たな危険地域集計ロジックは追加しない。

---

## 対象データ

利用:

```text
integrated_dangerous_regions
```

必要情報:

```json
{
  "label": "高知県付近",
  "lat": 33.56,
  "lng": 133.53,
  "events": [...]
}
```

---

## UI

### 危険地域カード

現在:

```text
1 高知県付近

・キキクル
・雨雲
```

↓

クリック可能にする。

カーソル:

```css
cursor: pointer;
```

---

## 地図フォーカス

クリック時:

```javascript
map.flyTo(
  [lat, lng],
  8
);
```

推奨。

---

## ズーム

初期:

```text
zoom=8
```

推奨。

ただし現在ズームが高い場合は過度に縮小しないこと。

---

## 強調表示

対象地域に一時的な強調表示を行う。

候補:

```text
CircleMarker
Pulse
Highlight ring
```

いずれか。

---

## 表示時間

推奨:

```text
3〜5秒
```

で自動消去。

---

## ポップアップ

フォーカス後に表示する。

例:

```text
高知県付近

キキクル（洪水）
雨雲
```

---

## 地震との整合

既存:

```text
地震一覧
↓
地図フォーカス
```

が存在する。

可能な限り共通処理を利用すること。

---

## ログ

クリック:

```text
live danger region focus:
label=高知県付近
lat=33.56
lng=133.53
```

---

## false-safe

以下を維持する。

* 危険度変更禁止
* ランキング変更禁止
* 集計変更禁止
* AI判定追加禁止

---

## 禁止事項

* dangerous_areas変更
* integrated_dangerous_regions集計変更
* navigation.js変更
* ナビ本体変更
* 津波/高潮/地震ロジック変更

---

## 完了条件

* 危険地域カードがクリック可能
* 地図へ移動できる
* 適切なズームになる
* 強調表示される
* ポップアップ表示される
* Docker正常起動
* /live正常表示
* ナビ本体へ影響なし
