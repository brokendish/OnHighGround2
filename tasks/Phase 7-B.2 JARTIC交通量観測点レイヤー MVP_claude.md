# Claude用実装指示書

## Phase 7-B.2

# JARTIC交通量観測点レイヤー MVP

## 目的

OnHighGround2本体の詳細地図上で、JARTIC交通量APIから取得できる交通量観測点データがどのように見えるかを実物確認する。

今回の目的は、道路交通レイヤーを完成させることではない。
JARTIC交通量APIは道路線データ・渋滞情報・規制情報ではなく、交通量観測点の点データとして扱う。

そのため、まずは以下に限定する。

```text
DBなし
履歴なし
変化率なし
道路名推定なし
OSM道路との最近傍マッチングなし
ランキング化なし
/live への本格表示なし
最新交通量の点表示のみ
```

## 重要な前提

JARTICへの問い合わせにより、以下が確認済み。

```text
交通量API仕様書には x-api-key 認証方式の記載がある
しかし現時点では利用者ごとのAPIキー発行・配布の仕組みはない
APIキー取得手続きや申請は不要
本APIは一般公開型のオープンデータAPIとして提供されている
```

したがって、実装上は **APIキー不要** として扱う。

既存実装または設計で以下のようになっている場合は修正すること。

```text
JARTIC_API_KEY 未設定時は unavailable
APIキーがない場合は取得しない
x-api-key が必須である
```

正しい扱いは以下。

```text
APIキーなしでJARTIC交通量APIへ取得を試みる
取得成功時は status: ok
取得失敗時のみ unavailable / error
```

## 今回扱うデータ

取得・正規化対象は以下。

```text
観測点
交通量
座標
上り交通量
下り交通量
小型交通量
大型交通量
観測時刻
観測点コード
```

取得データ上で判別できる場合のみ、以下も表示候補にする。

```text
集計単位: 5分値 / 1時間値
データ種別: 常設トラカン / CCTVトラカン
```

ただし、MVPでは基本項目の表示を優先する。

## 今回やらないこと

以下は今回のMVPでは実装しない。

```text
道路名推定
OSM道路との最近傍マッチング
道路線へのマッピング
交通量履歴の保存
通常比 / 変化率の算出
交通量ランキング
/live 側での本格表示
通行止め情報としての表示
規制情報としての表示
渋滞・混雑の断定
事故情報としての表示
道路ネットワーク形状の取得・描画
```

表示文言は必ず「交通量」に留める。
「渋滞」「混雑」「規制」「通行止め」「事故」など、JARTIC交通量API単体では断定できない表現は使わない。

## Backend実装方針

Backendでは以下を行う。

```text
JARTIC API取得
↓
GeoJSON取得
↓
必要なpropertiesだけ正規化
↓
最新JSONとしてキャッシュ
↓
frontendに返却
```

### APIキー

APIキーは不要。
環境変数 `JARTIC_API_KEY` が未設定でも取得処理を実行すること。

既存コードに `JARTIC_API_KEY` 必須判定がある場合は削除または無効化する。

### キャッシュ方針

DBは使わない。
履歴保存もしない。
最新スナップショットのみ保存する。

想定保存先:

```text
data_runtime/backend/jartic/latest_traffic.json
data_runtime/backend/jartic/manifest.json
```

既存ディレクトリ構成に合わせて調整してよいが、以下の方針は守ること。

```text
最新データのみ
履歴ファイルを増やさない
PostgreSQL等のDBを使わない
新規コンテナを増やさない
```

### Backend API

既存の命名規則に合わせて、以下のようなAPIを追加する。

候補:

```text
GET /api/jartic/traffic
```

または

```text
GET /api/traffic/jartic
```

既存の `/live` 用APIや交通系APIの命名規則があれば、それに合わせる。

### レスポンス例

frontendで扱いやすいように正規化して返す。

```json
{
  "status": "ok",
  "source": "JARTIC / 国土交通省交通量API",
  "updated_at": "2026-06-29T12:00:00+09:00",
  "items": [
    {
      "code": "xxxx",
      "lat": 35.0000,
      "lon": 139.0000,
      "up": 320,
      "down": 280,
      "total": 600,
      "small": 500,
      "large": 100,
      "observed_at": "2026-06-29T11:55:00+09:00",
      "unit": null,
      "type": null
    }
  ]
}
```

### 正規化ルール

座標がない、または不正なデータは frontend に渡さない。

交通量値が欠損している場合は `null` として扱う。
`0` は欠損ではなく有効な値として扱う。

合計値がAPI側にない場合は、可能であれば以下で算出する。

```text
total = up + down
```

ただし、片方が欠損している場合は無理に合計しない。
断定できない場合は `null` とする。

### エラー時

取得失敗時は以下のようなレスポンスを返す。

```json
{
  "status": "unavailable",
  "source": "JARTIC / 国土交通省交通量API",
  "updated_at": null,
  "items": [],
  "message": "交通量観測点データを取得できません"
}
```

重要:

```text
APIキー未設定を unavailable の理由にしない
通信失敗・レスポンス不正・パース失敗のみ unavailable / error
```

## Frontend実装方針

OnHighGround2本体側に交通量観測点レイヤーを追加する。

`/live` 側には本格表示しない。
今回の対象は OnHighGround2 本体の詳細地図。

### UI

既存のレイヤー切替UIに合わせて、以下を追加する。

```text
交通量観測点
ON/OFFトグル
```

初期状態は OFF を推奨する。
避難支援の主役は安全地点・ルートであり、交通量観測点は補助レイヤーのため。

### 表示範囲

全国全件を常時表示しない。
まずは現在の地図表示範囲BBOX内の観測点のみを表示する。

方針:

```text
レイヤーON時にAPI取得
地図移動・ズーム後に表示範囲内だけ描画
BBOX外のマーカーは表示しない
```

API側でBBOX絞り込みが簡単にできる場合は backend 側で絞ってよい。
難しければ frontend 側で全件取得後にBBOX内だけ描画してよい。

ただし、初期表示で全国全件を大量マーカー表示しないこと。

### マーカー

交通量観測点であることが分かる控えめな点マーカーにする。

注意:

```text
赤 = 危険
赤 = 渋滞
```

のように誤読される表現は避ける。

交通量が多い地点を軽く強調する程度は許容するが、MVPではシンプルな表示を優先する。

### ポップアップ

マーカータップ時に以下を表示する。

```text
交通量観測点

上り: 320台
下り: 280台
合計: 600台

小型: xxx台
大型: xxx台
観測時刻: 2026-06-xx xx:xx
観測点コード: xxxx
出典: JARTIC / 国土交通省交通量API
```

欠損値は `不明` または `-` と表示する。
`0` は `0台` と表示する。

取得データ上で判別できる場合のみ以下も追加してよい。

```text
集計単位: 5分値 / 1時間値
データ種別: 常設トラカン / CCTVトラカン
```

### 表示文言の注意

以下の文言は使わない。

```text
渋滞
混雑
通行止め
規制
事故
異常
危険
```

今回表示するのはあくまで交通量観測値である。

## 既存機能への影響を避けること

以下に影響を出さない。

```text
OnHighGround2本体の避難ルート表示
現在地表示
安全地点検索
津波警告UI
気象カード
/live 画面
既存の鉄道レイヤー
既存の道路レイヤー
```

特に `/live` は今回の主対象ではないため、不要なUI追加や表示変更をしない。

## テスト追加方針

可能であれば、以下のテストを追加する。

### Backend

```text
JARTIC_API_KEY 未設定でも取得処理が実行される
取得成功時 status: ok
取得失敗時 status: unavailable
0台が欠損扱いにならない
座標欠損データを除外する
latest_traffic.json が作成される
履歴ファイルが作成されない
```

### Frontend / E2E

```text
交通量観測点トグルが表示される
初期状態はOFF
ONにするとBBOX内の観測点マーカーが表示される
OFFにするとマーカーが消える
マーカークリックでポップアップが表示される
ポップアップに上り・下り・合計・小型・大型・観測時刻・観測点コード・出典が表示される
BBOX外の観測点は表示されない
/live 側に不要な表示が出ない
```

## 完了条件

以下を満たしたら完了。

```text
APIキーなしでJARTIC交通量API取得を試みる
取得成功時に正規化JSONを返す
取得失敗時のみ unavailable / error になる
最新スナップショットのみ保存する
DB・履歴・変化率を使わない
OnHighGround2本体に交通量観測点トグルがある
トグルONで地図表示範囲内の観測点がマーカー表示される
マーカータップで交通量ポップアップが表示される
表示文言が交通量に留まっている
/live 側に不要な影響がない
既存主要機能が壊れていない
```
