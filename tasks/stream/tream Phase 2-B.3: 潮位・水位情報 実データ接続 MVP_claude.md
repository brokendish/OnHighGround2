 # Claude用実装指示書

## `/live/stream` Stream Phase 2-B.3: 潮位・水位情報 実データ接続 MVP

## 目的

`/live/stream` 右下の **「潮位・水位」小窓** を、既存 `/live` 側の潮位データへ接続する。

Phase 2-B.1 では地震情報、Phase 2-B.2 ではキキクル・豪雨情報の実データ接続が完了した。
今回の Phase 2-B.3 では、信頼性のある既存潮位データを使い、配信用ビューの潮位・水位パネルを実データ化する。

今回の目的は以下。

```text
既存 /live の潮位データ
  ↓
stream用 tide/water adapter
  ↓
buildScene()
  ↓
潮位・水位小窓
潮位カーブ
現在潮位
満潮/干潮
偏差
ヘッダー潮位件数
必要に応じてテロップの潮位項目
```

---

## 重要方針

今回の主対象は **潮位データ** とする。

`/live` 側に安定した河川水位などの正規化済みデータが存在する場合のみ、水位も取り込んでよい。
存在しない場合は、右下小窓のタイトルは「潮位・水位」のままでもよいが、実接続対象は潮位に限定する。

今回やること:

```text
既存 /live の潮位データ取得口を利用する
潮位・水位小窓に実潮位データを表示する
2地点ずつ表示する
複数地点を8秒程度で巡回する
潮位カーブを実データから描画する
現在時刻マーカーを demoNow / 実時刻に連動させる
ヘッダー潮位件数を実データ由来にする
取得成功0件と取得失敗を区別する
```

今回やらないこと:

```text
新規backend APIの大規模追加
DB追加
潮位データ生成処理の作り直し
河川水位の新規データ取得
JARTIC交通量表示
鉄道実データ接続
地図のLeaflet/MapLibre差し替え
テロップ全面動的化
高潮警報ロジックの新規実装
```

## 1. 既存 `/live` の潮位データ取得口を調査する

まず、既存 `/live` がどのAPIや状態を使って潮位情報を表示しているか確認する。

調査対象候補:

```text
frontend/js/live/
frontend/js/live-stream/
backend /api/* tide 系
data_runtime/backend/tide/
data_runtime/backend/tide/jma/
既存 tide / sun / moon timeline 関連
```

確認すること:

```text
取得URL
レスポンス形式
地点一覧
地点名
地点コード
緯度経度
現在潮位
時間別潮位
満潮時刻/潮位
干潮時刻/潮位
偏差があるか
更新時刻
データ年/月/日
出典表示
```

既存 `/live` 側に正規化済みAPIがある場合は、それを優先して使う。
潮位データファイルをフロント側が直接読みに行く構成は避ける。

## 3. 表示対象地点の選択ルール

右下パネルは2地点表示を維持する。

### 基本表示

```text
2地点を上下に表示する
8秒ごとに次の2地点へ巡回する
地点数が2件未満の場合は存在する分だけ表示する
地点数0件の場合は対象なし表示にする
```

### 優先表示

高潮・注意状態などの警戒フラグが既存データから取れる場合は、以下を優先する。

```text
1. 警戒/注意状態の地点
2. 偏差が大きい地点
3. 現在潮位が高い地点
4. 満潮時刻が近い地点
5. 既定順
```

警戒判定が既存 `/live` 側に存在しない場合は、新規に複雑な判定を作らない。
MVPでは既定順または既存 `/live` の選択順でよい。

---

## 4. ヘッダー潮位件数の意味

ヘッダー右上の `潮位 n` は、全地点数ではなく **警戒対象地点数** とする。

```text
平常時:
  潮位 0

警戒地点あり:
  潮位 2

取得失敗:
  潮位 -
```

右下パネルには平常時でも代表地点を表示してよい。
つまり、以下の状態は正常とする。

```text
ヘッダー: 潮位 0
右下パネル: 東京 / 横浜 の潮位を表示
状態: 平常
```

これは「潮位データが0件」ではなく、「警戒対象が0件」という意味にする。

---

## 5. 潮位・水位小窓の表示内容

1地点ごとに以下を表示する。

```text
地点名
現在潮位
単位 cm
満潮時刻・潮位
干潮時刻・潮位
偏差
24時間潮位カーブ
現在時刻マーカー
状態ラベル
```

表示例:

```text
東京
155 cm

満潮 05:38 184cm
干潮 11:42 28cm
偏差 +6cm
```

値が存在しない場合は、無理に `null` や `undefined` を出さない。

```text
偏差不明の場合:
  偏差を非表示、または 偏差 --cm

満潮/干潮不明の場合:
  満潮 --:-- --cm
```

## 6. 潮位カーブ

潮位カーブは実データから描画する。

### 入力

可能なら24時間分の時間別潮位を使う。

```text
0時〜23時
または
現在時刻の前後12時間
```

既存APIの形式に合わせる。

### 描画

Phase 2-B.3 では、現在の簡易SVGカーブを継続使用してよい。
ただし、ダミーの正弦波ではなく、実潮位データの点列から path を作る。

### 現在時刻マーカー

Phase 2-A で整備した時刻ソースを使う。

```text
demoNow指定あり:
  demoNowの時刻で固定

demoNow指定なし:
  実時刻に追従
```

現在時刻マーカーは、`currentHourFloat` からX座標を計算する。

---

## 7. demoNow との関係

`demoNow` は継続使用する。

用途:

```text
時計固定
潮位カーブの現在時刻マーカー固定
現在潮位の算出基準
E2Eスクリーンショット安定化
```

`demoNow` 指定時は、可能であればその時刻に対応する潮位値を算出する。
時間別データがある場合は、線形補間して現在潮位を求めてよい。

例:

```text
19:30
19時潮位と20時潮位から補間
```

補間が難しい場合は、最も近い時刻の値を使う。

---

## 8. 現在潮位の算出

既存APIが現在潮位を返す場合は、それを優先する。

返さない場合は、時間別潮位データから算出する。

推奨:

```text
hourlyData がある:
  現在時刻の前後の値から線形補間

hourlyData がない:
  最も近い時刻の値

どちらもない:
  currentCm は null 扱い
  表示では --cm
```

`NaN` を出さない。

---

## 9. 出典・データ種別表示

パネル下部または小さな注記として、既存デザインに合う範囲で出典を表示する。

例:

```text
JMA 潮位データ
```

または

```text
出典: 気象庁潮位表
```

既存 `/live` の出典表記に合わせる。

重要:

* 実測値ではなく推算/予測値の場合は「観測」と断定しない
* 既存データの性質に合わせた表記にする

---

## 10. state / demo パラメータとの関係

### `state=calm`

強制平穏表示。
実データがあっても calm 表示を優先する。

```text
潮位パネル:
  平常表示
  demoNowに対応したデモ潮位表示でも可
```

### `state=alert&demo=1`

E2E安定用の警戒デモ表示。
潮位のダミーデータを必ず表示する。

### 通常表示

実データ取得を試みる。

```text
取得成功・地点あり:
  実潮位データ表示

取得成功・地点0:
  表示対象なし

取得失敗:
  取得不可表示
```

### `demo=1`

地震・豪雨・潮位すべてのデモ表示を安定化する。

---

## 11. 取得成功0件時の挙動

実データ取得に成功し、表示可能な潮位地点が0件の場合:

```text
潮位・水位小窓:
  現在、表示対象なし
  潮位データを監視中

ヘッダー:
  潮位 0

中央地図:
  潮位パルスなし
```

ただし、平常時でも代表地点を表示できる場合は、地点0件とは扱わない。

---

## 12. 取得失敗時の挙動

API取得失敗・パース失敗・ネットワークエラー時は、画面全体を壊さない。

表示例:

```text
潮位・水位情報
取得できません
```

または

```text
潮位・水位情報
一時的に取得不可
```

禁止:

```text
潮位異常なし
平常
```

取得失敗時に「平常」と断定しない。

console error は出さず、必要なら console.warn 程度にする。

---

## 13. 中央地図パルス

Phase 2-B.3 では、中央地図上の潮位パルスは必須ではない。

ただし、警戒対象地点がある場合のみ、紫〜マゼンタ系パルスを表示してよい。

```text
警戒対象あり:
  潮位パルス表示

警戒対象なし:
  潮位パルスなし
```

常時全潮位地点にパルスを出さない。
配信画面がうるさくなるため、警戒対象だけでよい。

---

## 14. テロップは最小対応

今回、テロップ全面動的化は対象外。

ただし潮位実データがある場合、潮位項目だけ最小限差し替えてもよい。

例:

```text
【潮位】東京 現在155cm / 満潮 05:38 184cm
```

やりすぎない。
テロップ全カテゴリ統合は Phase 2-C 以降。
