# タスク: 非ナビ時の現在地情報パネル実装

## 概要

情報タブに「非ナビ時の現在地詳細情報」をリアルタイム表示する機能を追加する。

---

## 要件

### 表示条件
- **ナビ中**: 現状のナビ情報を表示（変更しない）
- **非ナビ時**: 現在地の詳細情報をリアルタイムで表示（新規実装）

### タブ挙動
- **操作タブがデフォルト表示のまま変えない**
- 情報タブを自動的に前面に出さない
- ユーザーが情報タブを開いたときだけ内容を表示する

---

## 表示する情報（フル構成）

### A. 位置・GPS情報
| 項目 | 内容 |
|------|------|
| 緯度・経度 | 小数点6桁 |
| GPS精度 | ±XX m |
| 最終更新 | XX秒前 |

### B. 標高・ハザード情報
| 項目 | 内容 |
|------|------|
| 現在標高 | XX m（海抜） |
| 津波浸水域 | 該当 / 非該当 |
| 洪水リスク | 高 / 中 / 低 / 域外 |
| 土砂災害警戒域 | 該当 / 非該当 |

### C. 周辺情報
| 項目 | 内容 |
|------|------|
| 最寄りの避難場所 | 名称・距離・方角 |
| 最寄りの高台 | 標高・距離 |

---

## 実装方針

### 1. データ取得は既存処理を流用する

新規のwatchPositionやAPIコールを追加しない。
既存の以下を流用すること：
- `watchPosition` のコールバック（位置・精度）
- 標高取得の既存関数
- ハザードレイヤー判定の既存関数

```javascript
// 既存watchPositionのコールバック内に追記するイメージ
const onPositionUpdate = (position) => {
    // ... 既存のナビ処理 ...

    // 非ナビ時のみ情報パネルを更新
    if (!isNavigating()) {
        updateLocationInfoPanel(position);
    }
};
```

### 2. 情報パネルの更新関数

```javascript
const updateLocationInfoPanel = (position) => {
    // 情報タブが非表示でも更新は行う（開いたとき最新を表示するため）
    const { latitude, longitude, accuracy } = position.coords;

    renderSection('位置情報', { latitude, longitude, accuracy });
    renderSection('標高', getCurrentElevation());
    renderSection('ハザード', getHazardLayersAt(latitude, longitude));
    renderSection('周辺', getNearestShelterAndHighGround(latitude, longitude));
};
```

### 3. ナビ中と非ナビ中の表示切り替え

```javascript
// 情報タブの内容をモードで切り替え
const renderInfoTab = () => {
    if (isNavigating()) {
        showNavInfoContent();    // 既存：ルート情報
    } else {
        showLocationInfoContent(); // 新規：現在地情報
    }
};
```

### 状態表示

| 状態 | 表示 |
|------|------|
| 取得中 | `--` またはスピナー |
| 取得済み | 値を表示 |
| 取得失敗 | `取得できません` |
| ナビ中 | このパネル自体を非表示にして既存のナビ情報を表示 |

---

## DO NOT

- ❌ 操作タブをデフォルトから変更しない
- ❌ 情報タブを自動的に前面表示しない
- ❌ 新規のwatchPositionを追加しない
- ❌ ナビ中の情報タブ表示（既存）を変更しない
- ❌ バックエンド（FastAPI）を変更しない
- ❌ ハザードレイヤーの取得ロジックを変更しない
