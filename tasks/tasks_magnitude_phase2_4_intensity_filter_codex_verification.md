# Magnitude Phase2-4 検証指示書（CODEX）
## 震度フィルタ対応

## 目的

Magnitudeモードで震度フィルタが正しく動作し、地震リストと地図ピンの両方に反映されることを検証する。

また、Phase2-1 の避難所一時非表示、Phase2-2 の新着ハイライト、Phase2-3 の距離順ソートに回帰がないことを確認する。

---

## 検証対象

```text
Magnitude Phase2-4: 震度フィルタ
```

対象外:

```text
・WebSocketリアルタイム受信
・自動ポーリング
・避難誘導連動
・地域フィルタ
・期間フィルタ
```

# 3. フィルタ基本確認

モック可能であれば、以下のデータを使用する。

```json
{
  "items": [
    {
      "event_id": "eq-1",
      "occurred_at": "2026-04-29T10:00:00+09:00",
      "epicenter_name": "震度1",
      "lat": 35.1,
      "lng": 139.1,
      "max_intensity": "1",
      "magnitude": 2.1,
      "source": "mock"
    },
    {
      "event_id": "eq-3",
      "occurred_at": "2026-04-29T10:01:00+09:00",
      "epicenter_name": "震度3",
      "lat": 35.2,
      "lng": 139.2,
      "max_intensity": "3",
      "magnitude": 3.1,
      "source": "mock"
    },
    {
      "event_id": "eq-4",
      "occurred_at": "2026-04-29T10:02:00+09:00",
      "epicenter_name": "震度4",
      "lat": 35.3,
      "lng": 139.3,
      "max_intensity": "4",
      "magnitude": 4.1,
      "source": "mock"
    },
    {
      "event_id": "eq-5w",
      "occurred_at": "2026-04-29T10:03:00+09:00",
      "epicenter_name": "震度5弱",
      "lat": 35.4,
      "lng": 139.4,
      "max_intensity": "5弱",
      "magnitude": 5.1,
      "source": "mock"
    }
  ]
}
```

確認:

```text
全件:
  eq-1, eq-3, eq-4, eq-5w が表示される

震度3以上:
  eq-3, eq-4, eq-5w が表示される
  eq-1 は非表示

震度4以上:
  eq-4, eq-5w が表示される
  eq-1, eq-3 は非表示

震度5弱以上:
  eq-5w のみ表示される
```

リスト件数とピン件数が一致することも確認する。

# 4. 震度表記確認

以下の max_intensity を含むモックデータで確認する。

```text
5弱
5強
6弱
6強
7
5-
5+
6-
6+
null
不明
```

確認:

```text
・5弱/5-/5強/5+ は震度5弱以上で表示
・6弱/6-/6強/6+/7 は震度5弱以上で表示
・null / 不明 は全件では表示、震度条件付きでは非表示
・JSエラーが出ない
```

# 7. 新着ハイライト連携確認

Phase2-2 の新着差分をモックで確認する。

確認:

```text
・新着地震がフィルタ条件を満たす場合、NEW表示される
・新着地震がフィルタ条件を満たさない場合、リスト/ピンに表示されない
・新着件数表示が仕様どおり
・フィルタ変更後もNEW表示が破綻しない
```

# 8. API再取得後の状態維持

手順:

# 9. Phase2-1 避難所一時非表示回帰確認

確認:

```text
・避難所ON状態でMagnitude ON → 避難所ピン/広域クラスタ非表示
・Magnitude OFF → 避難所復元
・避難所OFF状態でMagnitude ON/OFF → OFF維持
・非同期の避難所取得戻りでゾンビ復活しない
```

---

# 10. 連続操作・増殖確認

手順:

```text
1. Magnitude ON/OFF を10回連続実行
2. 震度フィルタを複数回切替
3. ソート切替を複数回実行
4. 更新操作も複数回実行
```

確認:

```text
・MagnitudeパネルDOMが増殖しない
・地震リストDOMが重複しない
・地震ピンが増殖しない
・クリックイベントが多重登録されない
・選択状態は常に1件
・console error がない
```

# 13. 合格条件

以下をすべて満たすこと。

```text
・全件 / 震度3以上 / 震度4以上 / 震度5弱以上 が切り替えられる
・フィルタがリストとピンの両方に反映される
・震度5弱/5強/6弱/6強/7 が正しく判定される
・null/不明震度でJSエラーが出ない
・フィルタ後0件で空表示になる
・ソートとフィルタが同時に動作する
・NEW表示とフィルタが同時に動作する
・API再取得後もフィルタ/ソート状態を維持する
・Phase2-1/2/3に回帰がない
・DOM/ピン/イベントが増殖しない
・XSS対策が維持されている
```

---

# 14. NG条件

以下が1つでもあれば不合格。

```text
・フィルタ対象外の地震が表示される
・リストとピンで件数がズレる
・震度5弱/5強の判定が誤る
・null/不明震度でJSエラーが出る
・フィルタ後0件で古いピンが残る
・ソート状態が勝手に戻る
・NEW表示が壊れる
・避難所一時非表示が壊れる
・XSSが再発する
```
