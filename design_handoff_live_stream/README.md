# Handoff: 災害監視ライブ配信画面 (`/live/stream`)

## Overview
OnHighGround2 の `/live/stream` 向け、災害監視Live配信用の **1920×1080 固定・ダークテーマ**の監視卓風レイアウト。OBS/YouTube 配信でそのまま表示する「見るだけ（ユーザー操作前提なし）」の画面。全国で今何が起きているかを一目で把握させることが目的。

中央に日本全国地図、周囲に4つの小窓（地震／キキクル・豪雨／鉄道／潮位・水位）、上部ヘッダー、下部速報テロップで構成。`/live` の既存データを加工して表示する前提（本パッケージ内はダミーデータで動作）。

## About the Design Files
このバンドルの `index.html` は **HTML で作成したデザインリファレンス**です。意図した見た目・挙動を示すプロトタイプであり、そのまま本番投入するプロダクションコードではありません。

タスクは、この HTML デザインを **対象コードベースの既存環境（OnHighGround2 のフロントエンド：React / Vue / 素の JS など）で、その確立されたパターン・ライブラリを使って再現する**こと。既存の地図描画基盤（Leaflet / MapLibre 等）がある場合は、本デザインの簡略化 SVG 地図ではなく既存の地図コンポーネントに置き換えるのが望ましい（下記「地図について」を参照）。

なお `index.html` は単一ファイルでブラウザ / OBS ブラウザソースにそのまま表示できるため、**実装前の暫定配信・デザイン確認用としてはそのまま使うことも可能**。

## Fidelity
**High-fidelity (hifi)。** 最終的な配色・タイポグラフィ・余白・レイアウト・アニメーション挙動を含む。数値・色は下記「Design Tokens」および `index.html` の `:root` を正とし、ピクセル精度で再現すること。ただし**地図の国土形状は簡略化したスタイライズSVG**であり、本番では実地図に置き換える前提（形状の厳密な再現は不要）。

## Layout / 領域サイズ（1920×1080 固定）
ルート `.stage` = 1920×1080。3段構成（ヘッダー / 本文 / テロップ）。

```
┌──────────────────────────────────────────────────────────┐
│ HEADER  1920 × 72                                          │  名称 / 時計 / カテゴリ件数 / LIVE
├──────────┬───────────────────────────┬──────────────────┤
│ 左カラム   │        中央 全国マップ        │   右カラム        │
│ 476px     │        flex ( = 900px)      │   476px          │
│ ┌地震┐    │  全国の警戒地点をパルス表示    │  ┌鉄道┐          │
│ │458px│   │  平穏時「現在、表示対象なし」  │  │458px│         │
│ └────┘   │                             │  └────┘         │
│ ┌豪雨┐    │                             │  ┌潮位┐          │
│ │458px│   │                             │  │458px│         │
│ └────┘   │                             │  └────┘         │
├──────────┴───────────────────────────┴──────────────────┤
│ TICKER  1920 × 46                                          │  速報テロップ (marquee)
└──────────────────────────────────────────────────────────┘
```

- 本文領域高さ = 1080 − 72(ヘッダー) − 46(テロップ) = **962px**
- 本文 padding = 上下 16px / 左右 20px、カラム間 gap = **14px**
- 3カラム横幅: 左 476 + gap14 + 中央 flex(=900) + gap14 + 右 476 = 1880 ( = 1920 − 左右20)
- 各小窓高さ = (962 − 上下16 − gap14) / 2 = **458px**（`flex:1` で等分）
- フィット: プレビュー用に `.stage` を `scale(min(vw/1920, vh/1080))` で中央フィット。OBS(1920×1080)では scale=1。

## Screens / Views
単一画面。状態は2つ（+デモ）。URL パラメータで切替：
- `?state=calm` … 平穏時（固定）
- `?state=alert` … 警戒時（固定、8秒巡回あり）
- 既定（無指定）… 自動デモ（16秒 平穏 → 48秒 警戒 の64秒ループ）
- `?chrome=off` … 左上の状態切替ボタン（開発用UI）を非表示（配信時に使用）

### ヘッダー (`.hdr`, 高さ72)
- 左：ロゴ（照準リングSVG, 地震色）＋「全国災害監視ライブ」(22px/900) ＋ サブ「NATIONAL HAZARD WATCH · 監視卓」(mono 11px, letter-spacing .18em, `--ink-3`)
- 中央：時計 `HH:MM:SS`(mono 38px) ＋ 日付＋曜日＋JST(mono 12px)。毎秒更新。
- 右：カテゴリ件数バッジ4種（地震/豪雨/鉄道/潮位、各 `--c-*` 色）＋「LIVE」バッジ（`--c-alert` 背景、白ドット点滅 `blink` 1.4s）
- 背景 `linear-gradient(180deg,#0e1626,#0a0f19)`、下境界 `--line`。

### 中央 全国マップ (`.center`)
- 全国地図（`graticule` グリッド付き）に、**現在アクティブな全カテゴリの対象地点**をパルスマーカー表示（union）。
  - 地震：`--c-eq`、震度ラベル付き大マーカー
  - 豪雨：`--c-rain-2` マーカー＋雨域ブラー円（`--c-rain`）
  - 鉄道：`--c-rail` 小マーカーのみ（**ポップアップは出さない**）
  - 潮位：警戒拠点ごとに `--c-tide-2` 小マーカー
- 左上：「全国モニタ / NATIONWIDE · 監視中」
- 右上：警戒レベルピル。`data-lv="high"`（`--c-eq` 系）/ `"calm"`（`--c-safe` 系）。ドット点滅。
- 左下：大時計 `HH:MM`(mono 28px) ＋ 日付
- 右下：凡例（4カテゴリ色ドット）
- **平穏時**：地図の上に中央オーバーレイ `.center-empty`（リングアイコン＋「現在、表示対象なし」24px/800 ＋「ALL CLEAR · 全国の警戒情報を監視中」mono 12px）。

### 小窓共通 (`.win`)
- 枠線 `2px solid var(--win)`（カテゴリ色）＋ 同色の淡いグロー（`box-shadow` に `color-mix`）。**この枠色 = 中央地図のパルス色**（対応関係を色で示す設計）。
- ヘッダー `.win-hd`：和名(16px/800) ＋ 英名(mono 9px, カテゴリ色) ＋ 右にメタ情報 `.win-meta`。背景はカテゴリ色→透明のグラデ。
- 本文 `.win-body`：左に情報パネル（`.win-side`）、右に地図（`.win-map`）の2分割（潮位のみ例外、下記）。

#### 地震小窓 (`.win--eq`)
- 左パネル：「過去12時間の履歴」リスト（時刻 / 地点 / M / 震度チップ）。**履歴は平穏・警戒問わず常時表示**。
- 右地図：**現在選択中の地震イベントの震度マーカーのみ**表示（履歴の全点は出さない）。
- 複数イベント時：8秒ごとに対象を巡回。メタに「対象 n/N · 8s切替」＋巡回ドット(`cyc` アニメ)。
- 対象切替時、地図が **全国 → 該当地点へズームアップ**（下記アニメーション）。地名ポップアップ `.popup--eq`（`popIn` で遅延表示）。
- 平穏時：地図は全国表示、メタ「監視中」、地図中央に「現在 対象なし / 全国を監視中」。

#### キキクル・豪雨小窓 (`.win--rain`)
- 左パネル：「警報・注意報」リスト（色四角 + 地域 + レベルバッジ 危険/警戒/注意）。
- 右地図：対象地域の雨域ブラー円。ポップアップ `.popup--rain`。
- 複数地点時：8秒巡回。地震と同じズームアップ挙動。
- 平穏時：地震と同様のプレースホルダ。

#### 鉄道小窓 (`.win--rail`)
- **ごちゃつき回避のため、影響のある路線だけを太く表示**。地図上のポップアップは**出さない**。
- 左パネル：影響路線を**路線色付きカード**として縦に並べる（左の色バー = 路線色、路線名、区間/理由ノート、運行状況バッジ）。
- 右地図：首都圏路線図。影響路線のみ路線色で太線（山手線 6px、他 5px）、非影響路線は細いグレー(`#37445a` 3px)。
- 平穏時：メタ「平常運転」、左パネルに「影響路線なし / 平常運転」。地図は細線のみ。

#### 潮位・水位小窓 (`.win--tide`)
- **2拠点を上下に並べて同時表示**し、**8秒ごとに次の2拠点へ巡回**（プール6拠点をループ）。メタ「拠点 a・b/N · 8s巡回」。
- 各セル `.tide-cell`：左に情報（拠点名＋ドット、現在潮位 30px/mono ＋ cm、満潮▲/干潮▼/偏差）、右に24時間潮位カーブSVG。
- 高潮警戒の拠点：セル背景にマゼンタ帯（`.alert`）、「高潮警戒」フラグバッジ、カーブ＆現在値を上振れ、カーブ色をピンク(`#e879f9`)に。
- 潮位カーブは正弦近似モデル（`base + amp·sin(2π(t−phase)/12.42)`）。満潮/干潮点マーカー、現在時刻の縦破線＋現在点。

### テロップ (`.ticker`, 高さ46)
- 左「速報」タグ（`--c-alert` 背景）＋ 右に marquee（`--mono` 15px、34s ループ、テキスト2連結でシームレス）。

## Interactions & Behavior
- **時計**：毎秒更新（`setInterval` 1s）。デモ基準時刻 19:25:48 から加算（実装では実時刻に）。
- **状態巡回**：`tick`（秒）を基準に `Math.floor(tick/8)` で8秒サイクル。地震・豪雨の対象選択、潮位の拠点ペアがこれで進む。
- **再描画ガード**：`render()` は「モード変更 / 状態遷移 / 8秒サイクル進行」時のみ実行（`sig = mode|kind|floor(tick/8)` が変わった時）。毎秒フル再描画しない＝アニメーションのリセット防止・省負荷。時計は別 interval。
- **ズームアップアニメーション**（地震・豪雨）：対象切替のたびに地図の `<g>` transform を **全国ビュー(zoom1, cx500, cy650) → 対象ビュー(zoom≈3.1〜3.2)** へ `requestAnimationFrame` でトゥイーン。
  - duration = **900ms**、イージング = **easeOutCubic** (`1 − (1−x)³`)。
  - 実測progression例: scale 1 → 1.6 → 2.1 → 2.5 → 2.8 → 3.0 → 3.2。
  - マーカーは `scale(1/zoom)` の逆補正で画面上サイズ一定（ピンに寄っていく見え方）。雨域は地図と一緒に拡大。
  - ポップアップは `popIn`（.5s / delay .4s）で寄りが落ち着く頃に出現。
  - 平穏時はアニメーションなし・rAF キャンセル。
- **点滅**：LIVE / 警戒レベルドットは `blink` 1.4s。巡回インジケータは `cyc` 8s。
- レスポンシブ：本デザインは固定1920×1080。スマホ視聴は縮小フィットで「大まかな意味が伝わる」ことを狙う（レイアウトは変えない）。

## State Management
描画は純粋関数 `render(scene, tick)` に集約。状態は以下：
- `mode`: `'calm' | 'alert' | 'demo'`（URL `?state=` 由来）
- `tick`: 経過秒（毎秒 +1）。8秒サイクルと時計の基準。
- `lastSig`: 直近の描画シグネチャ（再描画ガード用）
- 各地図要素の `el.__raf`: 進行中のズーム rAF ハンドル（切替時に `cancelAnimationFrame`）
- 描画データは `scene`（= `SCENES.calm` / `SCENES.alert`）。これが**「/live を加工した後」のビューモデル**。

### `/live` データ差し替え方針（重要）
- `SCENES.calm` / `SCENES.alert` と同じ形の object を返す **`buildScene(rawLiveData)` を実装**し、その戻り値を `render()` に渡すだけで実データ表示になる。
- ビューモデルの形：
  - `earthquake: { targets: [{p,m,s,t,at:[x,y],r}], history: [{t,p,m,s,c}] }`
  - `rain: { targets: [{r,lv,lvColor,amt,at:[x,y],cells:[[x,y,radius,opacity]...]}], alerts: [{r,lv,cl}] }`
  - `rail: { affected: [{id,name,status,note,stColor}] }`（`RAIL_LINES_BASE` に路線ジオメトリ）
  - `tide: { stations: makeTide([警戒拠点名...]) }`（`TIDE_POOL` に拠点定義、`makeTide()` で潮位系列生成）
- 座標系：地図SVG viewBox `0 0 1000 1300`。`at:[x,y]` はこの座標。**実装では実地図の緯度経度から投影**する（下記）。
- `targets` が空 = そのカテゴリは平穏。全カテゴリ空 = 中央「表示対象なし」。

## 地図について（実装時の置き換え）
- 本デザインの日本地図は **手描きの簡略スタイライズSVG**（`MAP_PATHS`）。国土形状の正確さは意図していない。
- 本番では OnHighGround2 の既存地図基盤（Leaflet / MapLibre / 地理院タイル等）に置き換え、以下を移植：
  - ズームアップ = 地図ライブラリの `flyTo`/`easeTo`（duration 900ms 相当、easeOutCubic 近似）。
  - パルスマーカー = カテゴリ色の CSS パルス（`ring`/`core` keyframes 参照）。
  - 鉄道 = 影響路線のみ強調ポリライン、ポップアップなし。
  - 雨域 = ぼかし円 or ヒートレイヤ。
- マーカー/雨域/路線の**色ルールと挙動**（ズーム・巡回・ポップアップ有無）は厳守。地図の見た目そのものは既存タイルに従ってよい。

## Files
- `index.html` — 単一ファイル（HTML+CSS+JS一体）。デザインの全実装。
  - CSS: `:root` にトークン、`.hdr / .body / .win / .center / .ticker` ほか。冒頭コメントに領域図あり。
