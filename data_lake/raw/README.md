# data_lake/raw — 生データ置き場

各都道府県の各種ハザード・行政データの **ダウンロード済み原本** を格納する。
正規化・変換は行わず、入手したファイルをそのまま置くこと。

## 構成

```
data_lake/raw/
├── tokyo/       東京都
├── kanagawa/    神奈川県
└── {region}/    （将来追加）
```

各リージョンディレクトリは以下の共通サブディレクトリを持つ。

## 各リージョン共通のディレクトリ構成

| ディレクトリ | 内容 | 主なデータソース |
|---|---|---|
| `admin_boundaries/` | 行政区域データ（GML/SHP） | 国土数値情報 N03 |
| `boundary/` | 都道府県界・市区町村界 GeoJSON（正規化前原本） | 同上 |
| `dem/` | 数値標高モデル（GeoTIFF / CSV） | 国土地理院 DEM |
| `evac/` | 指定緊急避難場所・避難所データ | 国土数値情報 P20 / 各都道府県オープンデータ |
| `shelter/` | 避難所 GeoJSON（原本） | 同上 |
| `osm/` | OpenStreetMap PBF（都道府県単位 or 広域） | Geofabrik |
| `tsunami/` | 津波浸水想定 GML（A40 系） | 国土数値情報 |
| `flood/` | 洪水浸水想定 GML（A31a/A31b 系） | 国土数値情報 |
| `storm_surge/` | 高潮浸水想定 GML | 国土数値情報 |
| `inland_flood/` | 内水氾濫浸水想定 | 各都道府県 / 市区町村 |
| `landslide/` | 土砂災害警戒区域 GeoJSON/GML（A33 系） | 国土数値情報 |
| `urban_flood/` | 都市型浸水想定 | 各都道府県 / 市区町村 |

## ファイル命名規則

国土数値情報のダウンロードファイル名をそのまま使う。
都道府県コードはファイル名末尾の数字で識別する。

| 都道府県 | コード | 命名例 |
|---|---|---|
| 東京都 | 13 | `A40-23_13_GML.zip` |
| 神奈川県 | 14 | `A40-23_14_GML.zip` |
| 千葉県 | 12 | `A40-23_12_GML.zip` |
| 埼玉県 | 11 | `A40-23_11_GML.zip` |

## 注意

- このディレクトリ以下は `.gitignore` により Git 管理対象外（大容量バイナリのため）。
- 正規化済みデータは `data_lake/normalized/{region}/` へ、タイルは `data_lake/tiles/{region}/` へ出力する。
- 新しいリージョンを追加する際は、このディレクトリ以下に `{region}/` を作成し、上記の共通サブディレクトリを用意すること。
